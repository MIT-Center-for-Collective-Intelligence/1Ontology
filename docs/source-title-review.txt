Draft synchronization is independent of final submission, management, and
downloads. Edits persist immediately in browser recovery storage and debounce
server checkpoints by two seconds. Hidden active-time accumulation uses a ref
without rerendering the form each second. Timing-only checkpoints occur every
30 seconds, on pause, and when the tab is hidden. Unchanged paused drafts make
no network writes. Background checkpoints never change or disable the submit
button, freeze fields, or replace text typed during a request.

ReviewDraftWriter permits one draft write at a time. Final submission freezes
the chosen payload immediately, waits for any draft save, then uses its known
revision. Browser storage journals the in-flight checkpoint and the queued
submission intent. A lost response is reconciled against the exact server
payload/revision before writing again. Unknown final deliveries retry the
same immutable payload; definite validation rejections remain editable. Other
tabs' changes are not overwritten. Explicit conflict recovery retains the
unsent copy in separate browser storage and provides a recovery download.
Requests, including response-body reads, have a 30-second deadline.
