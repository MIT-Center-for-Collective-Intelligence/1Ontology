# Random 50 title-clarification review

This read-only dataset contains 50 reproducibly random atomic-activity title/evidence cases. The 18 cases from the prior reviewed round are excluded. The calibrated v7.4 prompt produced 7 keep, 8 rename, 35 split, and 0 defer proposals, for 138 proposed groups.

Rob's review is the semantic evaluation. Unreviewed cards are not agreements, and no response mutates the ontology. The round tracker begins at 0 reviewed and will count one current agree/disagree response per card.
